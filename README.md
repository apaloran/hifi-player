## hifi-tui-player

A minimalist, terminal-styled (`TUI`) lossless music player which plays from a private API of a friend of mine and also offers you an option to BYOK and play.

> [!NOTE]
> This project is made heavily with the assistance of AI and is for MY personal usage. There will not be any updates or features added on request and will only occur only in the case where I feel it is disruptive to me.

Only Linux AppImages are available at this moment.
